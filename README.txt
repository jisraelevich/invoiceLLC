# How to use the Invoice Planner Web App

1. Open a terminal (PowerShell or CMD).
2. Go to the folder: facturador_calculador
3. (First time only) Install dependencies:
   pip install flask
4. To start the web app, run:
   start.bat
5. Open your browser and go to: http://localhost:5050
6. Use the web interface to edit your monthly plan and click 'Generate facturas.csv' to export invoices for the AFIP system.
7. To stop the web app, run:
   stop.bat

Configuration:
- Edit config.py to change the JSON path, script path, or port.

Support:
- If you need help, contact your developer assistant.
